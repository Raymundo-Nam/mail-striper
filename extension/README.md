# Mail Striper

회사 웹메일의 HTML 링크를 분석하는 Chrome / Edge 확장 프로그램 프로토타입입니다.
**정상 주소를 사용자가 등록하지 않습니다. 보호할 사이트에서 한 번 켜면 자동으로 검사합니다.**

## 바로 체험하기

개발 서버가 실행 중이면 http://127.0.0.1:4173 에서 열 수 있습니다.
8가지 예시 메일에서 링크를 눌러 경고를 확인하세요. 체험 화면은 외부 링크로 이동하지 않습니다.
‘동적 링크 추가’는 새 HTML이 들어왔을 때 자동으로 다시 검사하는 기능을 보여 줍니다.

## Chrome / Edge에 설치하기

Chrome / Edge 133 이상을 사용합니다.

1. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 프로젝트 안의 **extension** 폴더를 선택합니다. ZIP으로 받은 경우 먼저 압축을 해제하고 `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 회사 웹메일을 연 뒤 Mail Striper 아이콘을 누릅니다.
6. **이 사이트 보호 켜기**를 누르고 해당 사이트 접근을 허용합니다.

빌드 결과가 포함되어 있어 설치에 Node.js나 별도 빌드가 필요하지 않습니다.
권한을 허용한 사이트는 다음 방문부터 자동으로 보호됩니다. 하위 도메인은 별도 사이트로 취급하며, Chrome의 사이트 권한은 포트별로 분리되지 않습니다.
현재 열려 있던 프레임 내부는 사이트를 새로고침한 뒤 적용될 수 있습니다.
이 프로토타입은 로컬에서 개발한 미배포 확장이므로 회사 관리 브라우저의 설치 정책에 따라 설치가 제한될 수 있습니다.

## 동작

- 화면의 URL과 `<a href>` 목적지의 등록 도메인 불일치를 탐지합니다.
- 현재 사이트의 등록 도메인, 링크에 표시된 주소, 내장된 주요 서비스 주소를 자동 비교 기준으로 사용합니다.
- 한두 글자 변경 / 인접 문자 순서 변경, 일부 닮은 문자, 도메인 끝부분 변경, 브랜드 이름에 단어 추가를 검사합니다.
- 하위 도메인, 경로·매개변수, URL 사용자 정보(`@` 앞부분)를 이용한 주소 위장을 검사합니다.
- 알려진 단축 주소와 이동 매개변수는 **목적지 미확인**으로 표시합니다.
- 알려진 Safe Links / Google URL 형식은 포함된 주소 문자열만 읽습니다. 실제 이동을 확인하거나 중간 서비스를 우회하지 않습니다.
- 링크에 색을 표시하고, 경고 근거를 모아 보여 주며, 클릭 시 확인 창을 엽니다.
- 클릭 경고는 링크 근처의 작은 팝업으로 표시합니다. 화면 가장자리에서는 위치를 조정하고, 상세 설명은 펼쳐서 확인합니다. 바깥 클릭이나 스크롤로 닫을 수 있습니다.
- 상시 떠 있는 위젯은 없습니다. 검사 결과는 확장 프로그램 아이콘의 ‘결과 보기’로 열 수 있습니다.
- 확장 팝업에는 현재 사이트, 보호 스위치, ‘검사 링크’와 ‘의심 링크’ 수만 표시하며 보호 사이트 목록은 접어서 보관합니다. ‘검사 링크’는 현재 페이지의 분석 대상 링크 수(메뉴 포함), ‘의심 링크’는 주의 또는 추가 확인으로 분류된 링크 수이며 사용자가 확인한 횟수가 아닙니다. 같은 주소의 링크가 여러 개 있으면 각각 셉니다.
- 편집 가능한 본문, 편집기 도구 모음, 인식되는 편집기 프레임은 검사에서 제외합니다. `javascript:void(0)` 같은 빈 동작 링크는 경고하지 않습니다.
- 일반 클릭 / 가운데 버튼 / 우클릭 / Enter 키를 처리하고, 클릭 순간에 바뀐 `href`도 다시 검사합니다.
- 주소가 바뀌지 않아도 HTML, 클래스, 표시 상태가 바뀌면 다시 검사하고 숨겨진 이전 화면은 제외합니다. 팝업과 결과 목록은 열린 동안 약 1초 간격으로 현재 문서를 다시 읽습니다. 문서당 최대 4,000개 링크, 결과 목록은 최대 80개를 표시합니다.
- ‘이번 한 번 열기’는 분석한 **원래 URL**을 새 탭에서 엽니다. 검사 중 링크를 먼저 방문하지 않습니다.
- 특수 링크도 ‘이번 한 번 실행’으로 원래 링크 동작을 이어갈 수 있습니다. 확장이 페이지 코드를 직접 평가하지 않으며 브라우저의 실행 정책은 적용됩니다.

## 첫 버전의 범위

이 버전은 **일반 HTML 링크 검사**가 중심입니다. 발신자 이름·발신 주소 자동 식별, 원본 메일 인증(SPF/DKIM/DMARC), 첨부파일 내용, 이미지 속 문자, QR 코드, 로그인 폼 검사는 아직 포함하지 않았습니다.

- 처음 보는 회사 주소에서 정상 주소의 근거가 없으면 글자 하나를 바꾼 위장을 놓칠 수 있습니다.
- URL 전체가 아니라 등록 도메인을 중심으로 비교하므로 같은 등록 도메인 안의 서로 다른 경로·일부 하위 도메인은 불일치 경고 대상이 아닙니다.
- 닮은 문자 대응표는 대표적인 라틴·키릴·그리스 문자만 포함하며 Unicode 전체를 포괄하지 않습니다.
- 새로운 도메인 / 정상 외부 서비스 / 사내 별칭 때문에 오탐이 생길 수 있습니다. 경고가 악성 판정을 뜻하지 않습니다.
- 페이지에 나타난 주소는 비교 단서이며, 이 확장 프로그램이 발신자의 진위를 인증하는 것은 아닙니다.
- 버튼에 연결된 임의 스크립트, 웹사이트가 직접 수행하는 이동, 브라우저 주소창 붙여넣기, Shadow DOM 내부 링크, 권한 없는 다른 출처 프레임, PC 메일 앱과 모바일 앱은 보호 범위 밖입니다.
- 페이지 내 경고는 브라우저 자체의 보안 경계가 아닙니다. 웹사이트의 스크립트나 겹치는 화면 요소가 방해할 수 있습니다.
- HTML 내용을 읽고 표시하므로 메일 수신 자체나 이미 로딩된 열람 추적 이미지를 차단하지 않습니다.
- 각 프레임은 독립적으로 검사하며, 팝업과 결과 목록은 접근 권한이 있는 프레임의 결과를 합산합니다. 보호 사이트가 만든 `about:blank` 등의 본문 프레임도 지원합니다. 같은 출처의 숨겨진 프레임은 제외하지만, 다른 출처 프레임은 부모의 숨김 상태를 읽을 수 없어 수치에 남을 수 있습니다.

## 개인정보와 권한

분석은 기기 안에서 수행됩니다. 외부 API, AI 서버, 분석 로그 전송, URL 사전 접속을 사용하지 않습니다.
사이트 선택은 브라우저의 선택적 호스트 권한으로 관리하며, 허용하지 않은 사이트에는 자동 주입하지 않습니다.
메일 내용이나 탐지 결과를 영구 저장하지 않습니다. 내장된 도메인 기준과 Public Suffix List는 패키지에 포함됩니다.

## 개발

```sh
npm install
npm run build
npm test
npm start
```

- `src/engine.js`: 순수 주소 분석 엔진. Public Suffix List를 포함한 `tldts`로 도메인 경계를 구분합니다.
- `src/guard.js`: HTML 검사, 동적 변화 감지, 링크 경고 UI와 클릭 보호.
- `extension/`: 그대로 설치할 수 있는 Manifest V3 확장.
- `demo/`, `src/demo.js`, `dist/`: 테스트용 받은편지함과 빌드된 체험 화면.
- `tests/`: 탐지·오탐·동적 변경·클릭 차단 회귀 테스트.

외부 의존성 코드는 빌드 시 포함하며 런타임에 내려받지 않습니다. 라이선스는 `extension/THIRD_PARTY_NOTICES.txt`에 포함됩니다.

## 검증

자동화 테스트는 주소 정규화, 도메인 경계, 보안 경유 링크, Unicode 위장, 동적 링크 추가, 클릭 취소, 확인 후 이동, 안전한 텍스트 표시를 다룹니다.
체험 웹페이지에서 실제 브라우저 렌더링과 경고를 확인했습니다. 실제 회사 웹메일과 설치된 확장 전체 동작은 설치 후 확인이 필요합니다.
